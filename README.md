🚦 Automatic Street Light Dimming System

📌 Overview

The Automatic Street Light Dimming System is a hybrid project that combines Arduino hardware and Python software to control street light intensity based on movement detection.
This system helps in reducing energy consumption by dimming or turning off lights when no activity is detected.

 🎯 Objectives

* Reduce electricity consumption
* Automate street lighting system
* Demonstrate smart energy-saving techniques


 🚀 Features

* 🔍 Motion detection-based control
* 💡 Automatic light ON/OFF or dimming
* ⚡ Energy-efficient solution
* 🖥️ Real-time monitoring using Python


 🛠️ Tech Stack

* **Programming Languages:** Python, Arduino (C++)
* **Hardware:** Arduino Board, Motion Sensor
* **Software Tools:** Python environment


⚙️ Working Principle

1. Motion sensor detects movement
2. Arduino processes sensor data
3. If movement is detected → Light turns ON / Bright
4. If no movement → Light dims or turns OFF
5. Python script monitors and simulates system behavior

 ▶️ How to Run

### 🔹 Arduino Setup

1. Open `street_light_dimming.ino` in Arduino IDE
2. Upload the code to Arduino board
3. Connect motion sensor properly

### 🔹 Python Setup

1. Install required libraries:
   pip install -r requirements.txt

2. Run the Python script:
   python src/monitor_realtime.py
